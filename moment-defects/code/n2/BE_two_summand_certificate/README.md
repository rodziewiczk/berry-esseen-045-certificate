# Berry--Esseen: exact two-summand certificate and continuation

Date: 6 September 2026.

## Mathematical result

For every real random variable X with E X = 0, E X^2 = 1 and
rho = E|X|^3 < infinity, and independent copies X1,X2,

    sup_x |P((X1+X2)/sqrt(2) <= x) - Phi(x)| <= (2/7) rho.

Equivalently C_2 <= 2 sqrt(2)/7 = 0.404061017820884... < C_E.

This is a computer-assisted proof, with a complete analytic reduction in
Two_summand_certificate.pdf and 70 exact rational polynomial certificates.
It is not a claim to have computed the optimal C_2, a priority claim, or a
proof of the conjecture at all sample sizes.

The proof does NOT assume finite support, the project's eventual theorem,
an effective N_0, the near-lattice transfer, or the earlier local interval
calculations. Its external numerical probability input is Shevtsova's
published structural bound 0.3322(1+0.429/rho) for the normalized constant.
The moment-defect factorization from the student note is proved again here.

## Reproduce the finite certificate (Python standard library only)

From this directory run:

    python tensor_certificate.py check
    python independent_integer_check.py
    python check_n3_obstruction.py

Expected final acceptance lines of the first two commands:

    ACCEPTED_ALL_70_TENSOR_CELLS 35878 134
    ACCEPTED_ALL_70_BY_INDEPENDENT_INTEGER_CHECK 35878 18426 134

The first implementation uses exact rational Bernstein coefficients and
exact subdivision. The second imports no code from the first and recomputes
homogeneous integer polynomial coefficients on each child triangle. Both
check the whole continuous support and moment domains, not sample grids.
Both check all 70 consecutive threshold intervals, both outside-threshold
reductions, and the numerical constants used in the extremizer reduction.
Missing or additional shards, incorrect coverage, invalid schemas and
undecided positivity are rejected. A partial diagnostic run of the second
implementation is explicitly NOT a global acceptance.

The supplied checks were run with CPython 3.13.5 on Linux x86_64. Their
acceptance paths require no SciPy, NumPy, SymPy, arbitrary-precision library,
platform Gaussian cdf, or floating-point arithmetic. They should also run
on Python 3.10 or newer; that wider version range has not been exhaustively
tested. The supplied logs record the complete runs.

The optional exact algebra audit requires SymPy:

    python verify_algebra.py

Its assertions check the fourth-moment defect algebra and normalization
identities; it is not needed for the 70-cell certificate acceptance.

## What is actually being certified?

There are 70 files certificate/000.json through certificate/069.json,
each containing 15 rational coefficients and its exact threshold endpoints.
For each threshold cell [a,b] the data define a piecewise polynomial M(u,v)
which satisfies, on the full square [-6,6]^2,

    M(u,v) >= 1{u+v <= b}.

For every admissible pair (gamma,rho) with 1 <= rho <= 2, its exact i.i.d.
expectation satisfies

    E M(X1,X2) <= Phi(a/sqrt(2)) + (2/7)rho.

The Gaussian cdf is bounded by rational alternating series and Machin bounds
for pi. Sign changes of |u|^3 and the event hyperplane are split exactly;
ties and atoms are included. The continuous moment region is subdivided and
checked with exact quadratic Bernstein coefficients.

The analytic part proves that any counterexample to this bound would have a
global maximizing witness on (-6,6), with rho < 2. Therefore verification on
this bounded class proves the unrestricted two-summand result. No numerical
truncation argument is used.

## Other results in the note

1. An exact exchangeable DEPENDENT triple has gamma=3/8, rho=6/5 and every
   symmetric tensor moment generated by (1,x,x^2,x^3,|x|^3) equal to its i.i.d.
   value, yet a normalized cdf score > 41/100 > C_E. The 35 rational orbits
   are in n3_dependent_obstruction.json. The checker verifies every identity
   and independently proves dependence via E[Y1^4 Y2] != 0.

   THIS IS NOT AN I.I.D. COUNTEREXAMPLE. It proves a limitation of one chosen
   moment relaxation, and shows why adding grid points cannot fix it.

2. For bounded |X|<=R, an explicit coefficient M_R(gamma) bounds

       0 <= E X^4 - 1 - gamma^2 <= M_R(gamma) d,

   where d is the exact two-point defect. Hence the characteristic-function
   comparison is bounded by M_R d |t|^4/24. For R=5 and matching Bernoulli
   parameter p in [2/5,11/25], M_R < 9. This gives a quartic low-frequency
   estimate with coefficient 3/8. It does not yet bound the full cdf distance.

3. A second-variation argument excludes three distinct fully populated
   atomic reflection orbits about an active midpoint for an n=2 maximizer.
   It does not bound all unpaired atoms.

## Proof and trust boundary

The checkers verify finite polynomial inequalities and arithmetic constants;
they do not formalize the analytic probability, compactness, variation or
interpolation arguments. The entire package is not Lean-verified. Both
implementations share CPython and its integer/rational arithmetic. Independent
mathematical review of the analytic reduction and of the checker is appropriate.
An error in candidate generation cannot make an invalid inequality pass either
exact checker, assuming faithful execution and correct checker logic.

Optional candidate construction uses scipy.optimize.linprog:

    python tensor_certificate.py generate --directory new_certificate

It is not required to verify the supplied data. The additional
build_n3_obstruction.py is also untrusted construction code; it uses SciPy
and SymPy. Its output is checked separately by the standard-library script.

SHA256SUMS binds the provided source, proof, logs and certificate data. Hashes
detect changes; they are not a substitute for review or mathematical proof.
