C5 source-bound semantic composition
===================================

This directory is a POST-HOC IMPLICATION CHECKER, not an execution certificate.
It never observes a subprocess, never issues a fresh C5 theorem, and never
uses the archived C5_CHECKED.json status as proof. That archived file is used
only through its pinned SHA-256 as the original source-byte selection index.

The checker requires NEW arithmetic artifacts from the existing guarded
adapters. It joins the same complete INITIAL INPUT (SHA, profile, rho/beta
domain, stages, final invariants and full2592-cell/100-panel cover), the whole
source-bound support/HIGH/owncap domains, all15 selected RESOURCE variants,
all295 separately replayed count forests, the whole-line gap-free rectangle,
and the41-strip/42-attempt complement plus the cited Shevtsova tail.

The exact count interface and geometry functions are extracted UNCHANGED from
the pinned independent source helpers. Their AST/source hashes are reported.
No original helper main, interval evaluator, native count acceptor, Gaussian
leaf evaluator or numerical integration is invoked by those functions.
The complement loader additionally rechecks the existing worker's algebraic
acceptor/readback comparisons and mutation controls; it does not reintegrate.

All twelve domains and all closed p seams are checked. Total obligations:
1200 probability panels =905 resource exclusions +295 count forests,
1770 count roots,148586 nodes,75178 leaves; separate gap-free forest:
60 roots,1994 nodes,1027 leaves. The final rho/beta arrangement includes
vertices, open edges and open cells, not just sample interior points.

The output always has execution_observed_by_this_reader=false,
fresh_parent_fact_joins_verified=false, c5_theorem_freshly_verified=false,
and all_index_conclusion_verified=false. The actual mathematical statement is
conditional on the specified arithmetic executions AND the retained analytic
premises: sharp all-law C4, unrestricted contact/attainment/support reduction,
INITIAL/resource/count implications, Prawitz and the cited Shevtsova inputs.

Only a different controller which observes its OWN guarded subprocesses may
discharge the execution condition. A plausible JSON/capture/PASS/hash is not
historical execution authentication. This checker has no --trust-pass or
--assume-fresh option and cannot be upgraded by a caller-provided Boolean.

API and invocation (from moment-defects/)
---------------------------------------
python -B -S -m unittest reproduction.c5_composition.test_semantics -v

python -B -S -m reproduction.c5_composition.compose --cache CACHE
    --archive cutoff5_20261020.zip --inputs INPUTS.json

INPUTS.json selects explicit observed-run artifact paths, with these fields:
support: FRESH_SUPPORT_RESULT.json
high: FRESH_HIGH_RESULT.json
owncaps: FRESH_OWNCAPS_RESULT.json
initials: mapping ALL12 INITIAL job_ids to FRESH_INITIAL_ARITHMETIC_RESULT.json
resources: mapping ALL15 RESOURCE job_ids to RESOURCE_ARITHMETIC_RESULT.json
counts_progress: C5_COUNTS_PROGRESS.jsonl (complete295-job run)
corner: capsule/FRESH_GAPFREE_RESULT.json
complement: FRESH_COMPLEMENT_SUPERVISOR_RESULT.json

No ready-made success file is supplied. Missing arithmetic artifacts, parent
domains, panels, roots or exterior/tail seams fail closed. The test suite uses
small synthetic mutations and pinned SOURCE fixtures, not an alleged new
mathematical replay. It does not exercise the expensive numerical producers.
